Private remote access

Reach Sage from your own devices over your Tailscale tailnet using HTTPS.

Enable tailnet access

Keep Sage bound to localhost. On the Sage computer, install/sign into Tailscale, then run this command in a terminal:

tailscale serve localhost:8000

Tailscale Serve shares Sage with devices allowed by your tailnet access policy. Use Serve, not Funnel; Funnel makes services public. Limit tailnet access to your own devices/users. Sage has no separate login screen, so anyone allowed to reach this service can use Sage with the host account’s permissions.
